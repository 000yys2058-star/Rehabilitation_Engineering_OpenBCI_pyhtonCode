# OpenBCI Ganglion 근전도(EMG) 실습

UNIST **재활재생개론** 수업용 실습 코드.
BLED112 동글로 OpenBCI Ganglion 보드에 연결해 **근전도(EMG)** 를 수집하고 처리합니다.

> ⚠️ **이 프로젝트는 EMG 전용입니다.** 뇌파(EEG)는 다루지 않습니다.
> 같은 보드로 뇌파도 잴 수 있지만, 전극 위치와 주파수 대역이 완전히 다릅니다.
> 여기서는 팔 근육에 전극을 붙이고 EMG 대역(20–95 Hz)만 남깁니다.

MATLAB Live Script 실습을 **Jupyter Notebook**으로 옮긴 것으로,
설명과 코드가 한 화면에 함께 있어 단계별로 따라가며 학습할 수 있습니다.

---

## 준비물

- **OpenBCI Ganglion 보드** — 4채널 · 200 Hz
- **BLED112 USB 동글**
- **EMG 전극** — 팔뚝에 부착
- Python 3.9 이상

> Ganglion 의 최대 표현 주파수는 **100 Hz**(= 200 ÷ 2, 나이퀴스트)입니다.
> EMG 는 원래 450 Hz 까지 성분이 있으므로 위쪽 절반은 볼 수 없지만,
> **신호의 세기(RMS)** 를 쓰는 용도에는 충분합니다.

## 실습 흐름

```
팔 근육 EMG ──BLE──> BLED112 동글 ──> BrainFlow ──> 행렬 (채널 × 시간)
                                                          │
                                              필터 (20-95Hz + 60Hz 노치)
                                                          │
                                              ┌───────────┴───────────┐
                                             RMS                 MDF / MNF
                                        (근육 활동량)           (근피로 지표)
                                              └───────────┬───────────┘
                                                      CSV 저장
```

| 단계 | 내용 |
| --- | --- |
| 1–2 | 라이브러리 준비, COM 포트 찾기 |
| 3–4 | 설정, 보드 사양 확인 |
| 5 | 연결 (내 보드 확인 게이트 포함) |
| **5-B** | **전극 임피던스 점검** — 접촉이 좋은지 숫자로 확인 |
| **5-C** | **전극 종류 비교 실험** (선택) — 임피던스·잡음·60Hz 를 기록해 비교 |
| 6 | 신호 수집 |
| 7–8 | 표로 정리, 원본 신호 확인 |
| 9–10 | 필터링, 전후 비교 |
| 11 | RMS — 근육 활동량 |
| 12 | 주파수 분석 — 중앙주파수(MDF)·평균주파수(MNF), 근피로 지표 |
| 13–14 | CSV 저장, 연결 해제 |

## ⚠️ 여러 보드를 동시에 쓸 때 (강의실)

### MAC 지정은 통하지 않습니다

`BOARD_MAC` 을 넣어도 **보드가 선택되지 않습니다.** BrainFlow 가 값을 받아
로그에 찍기는 하지만 실제 필터링에는 쓰지 않아, **먼저 응답한 보드에 연결**됩니다.

실측 근거 (2026-07-24, 보드 2대):

| 지정한 MAC | 결과 |
| --- | --- |
| `f6:83:23:ca:c1:29` (실제 보드 A) | 연결됨 |
| `c5:cf:b4:83:e8:c6` (실제 보드 B) | 연결됨 |
| `11:22:33:44:55:66` (**존재하지 않는 가짜**) | **연결됨** ← MAC 이 무시된다는 증거 |

BrainFlow 로그도 `search for 11:22:33:44:55:66` 를 찍은 뒤 그냥 연결합니다.

### ✅ 해결: 고를 수 없다면 고를 여지를 없앤다

연결하는 순간 **켜져 있는 보드가 하나뿐**이면, 선착순이든 뭐든 **반드시 그 보드에 연결**됩니다.

노트북의 **「내 보드 확인」 셀**이 이것을 강제합니다.

| 상황 | 동작 |
| --- | --- |
| Ganglion **1대** | 통과. 그 보드 이름을 표시하고 연결 허용 |
| Ganglion **2대 이상** | **연결 차단.** 다른 보드를 끄라고 안내 |
| **0대** | 전원·배터리 점검 안내 |

게이트를 통과하지 않으면 연결 셀이 실행되지 않습니다.

```
==============================================================
Ganglion 1대 - 안전하게 연결할 수 있습니다
==============================================================
  Ganglion-c57c   c5:cf:b4:83:e8:c6   신호 -73 dBm

  다음 셀에서 연결하면 반드시 이 보드에 연결됩니다.
```

여러 대일 때:

```
==============================================================
경고 - Ganglion 이 2대 켜져 있습니다
==============================================================
  Ganglion-3587        f6:83:23:ca:c1:29   신호  -61 dBm
  Ganglion-c57c        c5:cf:b4:83:e8:c6   신호  -73 dBm

  해결: 내 보드만 남기고 나머지 전원을 끈 뒤 이 셀을 다시 실행하세요.
```

### 📋 강의실 진행 순서

```
① 모든 보드 전원 OFF
② 1번 학생만 자기 보드 ON → 「내 보드 확인」 통과 → 연결 → 유지
③ 2번 학생만 자기 보드 ON → 「내 보드 확인」 통과 → 연결 → 유지
④ 이후 반복
```

연결된 보드는 광고를 멈추므로 다음 학생에게 잡히지 않습니다.
따라서 **각자 자기 보드에 정확히 연결**됩니다.

> 실측 확인: 가까운 보드(-61 dBm)를 막고 먼 보드(-73 dBm)만 남기니
> BrainFlow 가 먼 보드에 연결됐습니다. "1대만 켜져 있으면 그 보드"가 보장됩니다.

### 연결되면 어느 보드인지 알려줍니다

연결 성공 시 **광고명(advertised name)과 MAC 주소**를 표시합니다.

```
========================================================
연결된 보드
========================================================
  광고명 (advertised name) : Ganglion-c57c
  MAC 주소                 : c5:cf:b4:83:e8:c6
  신호 세기                : -69 dBm
========================================================
```

이 정보는 `CONNECTED_BOARD` 변수에도 담겨 뒤 단계에서 쓰입니다.

| 어디에 남는가 | 내용 |
| --- | --- |
| **1차시 CSV** | 파일명에 보드명, `board_name` · `board_mac` 열 추가 |
| **2차시 모델** | `.joblib` 메타데이터에 보드 정보 저장 |

2차시에서 **저장한 모델을 불러올 때 학습에 쓴 보드와 지금 보드가 다르면 경고**합니다.
전극 위치가 달라 정확도가 떨어질 수 있기 때문입니다.

> `Ganglion-c57c` 같은 이름은 BLE 표준에서 **Complete Local Name**(AD type 0x09)이고,
> 흔히 **advertised name** 이라고 부릅니다. OpenBCI GUI 에 표시되는 이름과 같습니다.

### 추가 안전장치

연결한 뒤 **팔에 힘을 줘 보세요.** 신호가 반응하면 내 보드입니다.
2차시 노트북의 5단계(실시간 신호 확인)가 이 역할을 겸합니다.

## 🔌 전극 임피던스 점검 (5-B · 5-C)

전극 접촉 불량은 이 실습에서 **가장 흔한 실패 원인**입니다.
파형만 봐서는 "좀 지저분한데?" 정도로만 알 수 있지만,
임피던스는 **어느 전극이 문제인지 콕 집어** 줍니다.

```
==============================================================
전극 임피던스
==============================================================
  Ch1             8.2 kΩ   [O] 좋음
  Ch2            34.5 kΩ   [△] 보통 - 가능하면 다시 붙이세요
  Ch3           120.7 kΩ   [X] 나쁨 - 다시 붙이세요
  Ch4             6.1 kΩ   [O] 좋음
  기준(REF)       4.3 kΩ   [O] 좋음
==============================================================
```

기준: **10 kΩ 미만 좋음 / 50 kΩ 미만 보통 / 그 이상 나쁨**.
전극을 아예 안 붙이면 400 kΩ 안팎이 나옵니다.

> **REF 전극이 나쁘면 모든 채널이 나빠집니다.** 노트북이 이 경우를 따로 알려줍니다.

### 전극 종류 비교 실험 (5-C)

**OpenBCI GUI 에는 임피던스를 저장하는 기능이 없습니다.**
이 노트북은 측정값을 CSV 에 누적해 **전극 종류별로 비교**할 수 있습니다.

전극을 바꿔 가며 이름만 적고 실행하면 결과가 쌓이고, 2종류 이상이면 비교 그래프가 나옵니다.

| 지표 | 의미 |
| --- | --- |
| 임피던스 (kΩ) | 전극-피부 접촉 저항 |
| 잡음 RMS (µV) | 힘을 뺀 상태에서 남는 신호 = 잡음 |
| 60 Hz 비율 (%) | 전체 파워 중 전원 잡음의 몫 |

임피던스가 높은 전극일수록 잡음과 60 Hz 도 함께 커집니다.
**세 지표가 같이 움직이는 것**을 확인하는 것이 이 실험의 핵심입니다.

기록 위치: `outputs/electrode_comparison.csv`

### 기술 메모 — 단위 환산

BrainFlow 의 `resistance_channels` 원시값을 **2로 나누면 kΩ** 입니다.
OpenBCI GUI 와 값을 대조해 확인했습니다 (원시 773 → 386.5 kΩ, 959 → 479.5 kΩ).

```python
board.config_board('z')   # 임피던스 모드 시작
# ... 10초 이상 수집 ...
board.config_board('Z')   # 종료 (자동으로 EMG 모드 복귀)
```

임피던스 모드에서는 EMG 대신 임피던스 값이 **초당 1개 정도**로 느리게 옵니다.

## ⚠️ brainflow 버전 주의

**`brainflow` 를 최신 버전으로 올리지 마세요.** 연결이 안 됩니다.

| 버전 | 결과 |
| --- | --- |
| **5.20.0** | ✅ 정상 연결 |
| 5.21 이상 | ❌ BLED112 지원이 죽어 있어 실패 |

`requirements.txt` 에 `brainflow==5.20.0` 으로 고정되어 있고,
노트북 1단계 셀이 버전을 확인해 자동으로 맞춰 줍니다.

### 버전을 바꾼 뒤에는 반드시 커널 재시작

`brainflow` 를 새로 설치하거나 버전을 바꿨다면 **`Kernel → Restart Kernel`** 을 해야 합니다.

DLL은 한 번 메모리에 올라가면 **파일을 교체해도 실행 중인 커널 안에서는 바뀌지 않습니다.**
재시작하지 않으면 디스크는 5.20.0인데 커널은 옛 버전을 계속 쓰면서
**0초 만에 연결 실패**합니다.

노트북 1단계 셀이 이 상황을 감지해 알려주고, 정상일 때는 이렇게 표시됩니다.

```
준비 완료
  BrainFlow : 5.20.0   (실제 로드된 버전)
```

OpenBCI GUI v5도 같은 라이브러리를 쓰기 때문에 동작이 동일합니다.

| --- | --- |
| `serial_port` | **필수.** 동글이 꽂힌 COM 포트 |
| `mac_address` | 선택. 비우면 자동 탐색 |
| `timeout` | 선택. 기본 15초 |

## 2차시 · 실시간 손동작 분류

`Ganglion_Tutorial_2_Classification.ipynb` — 팔뚝 EMG로 **가위·바위·보를 실시간 판별**합니다.

```
팔 근육 EMG → 필터(30-95Hz) → 특징 추출(포락선 평균)
   → 캘리브레이션(동작×40회) → Random Forest → 모델 저장 → 실시간 판정
```

1차시가 EMG 신호를 **보는** 것이었다면, 2차시는 같은 신호로 **판단**합니다.
`scikit-learn` 이 추가로 필요하며 `requirements.txt` 에 포함되어 있습니다.

**핵심 설계**
- 학습한 모델을 `joblib` 로 저장 → 다음 주에 불러와 비교 (전극 위치·개인차 실험)
- 시간순 분할로 정직하게 평가 (무작위 분할은 이웃 샘플 누수로 과대평가)
- 최근 5회 예측 다수결로 실시간 판정 안정화
- **관문 2곳**: 실시간 신호 확인(5단계), 활성 지문 확인(8단계) — 여기서 전극 문제를 미리 걸러냄

## 과제 아이디어

**기초**
- 힘을 약·중·강으로 나눠 주며 RMS 가 단계별로 오르는지 확인
- 저역 차단(`LOW`)을 5/20/40 Hz 로 바꿔 움직임 잡음 변화 관찰
- 노치 필터를 끄고 스펙트럼의 60 Hz 부근 확인
- 주먹을 30초 이상 세게 쥐고 MDF 가 내려가는지(근피로) 확인

**응용**
- 팔뚝 안쪽/바깥쪽으로 전극을 옮기며 채널별 RMS 비교
- 손목을 굽힐 때와 펼 때 어느 채널이 활성인지 지도 그리기
- RMS 임계값으로 주먹 쥠/폄 자동 판정
