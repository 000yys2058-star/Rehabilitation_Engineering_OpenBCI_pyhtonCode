# OpenBCI Ganglion 신경신호 실습

UNIST **재활재생개론** 수업용 실습 코드.
BLED112 동글로 OpenBCI Ganglion 보드에 연결해 신경신호(EEG/EMG)를 수집하고 처리합니다.

MATLAB Live Script 실습을 **Jupyter Notebook**으로 옮긴 것으로,
설명과 코드가 한 화면에 함께 있어 단계별로 따라가며 학습할 수 있습니다.

---

## 준비물

- **OpenBCI Ganglion 보드** — 4채널 · 200 Hz
- **BLED112 USB 동글**
- Python 3.9 이상

---

## 시작하기

### 1. 설치

```powershell
pip install -r requirements.txt
```

### 2. 노트북 실행

```powershell
jupyter notebook src/Ganglion_Tutorial.ipynb
```

브라우저가 열리면 **셀을 위에서 아래로** 하나씩 실행합니다 (`Shift + Enter`).

### 3. 설정

노트북 **3단계 셀**에서 세 가지만 고치면 됩니다.

```python
COM_PORT     = 'COM3'      # 동글 포트 (2단계에서 확인)
BOARD_MAC    = ''          # 연결할 보드 지정 (비우면 자동 탐색)
DURATION_SEC = 10          # 수집 시간
```

> ⚠️ **OpenBCI GUI는 반드시 종료하세요.** 동글은 한 번에 한 프로그램만 쓸 수 있습니다.

## 실습 흐름

```
Ganglion 보드 ──BLE──> BLED112 동글 ──> BrainFlow ──> 행렬 (채널 × 시간)
                                                          │
                                                        필터
                                                          │
                                              ┌───────────┴───────────┐
                                             RMS                  주파수 분석
                                           (신호 세기)            (대역별 파워)
                                              └───────────┬───────────┘
                                                      CSV 저장
```

| 단계 | 내용 |
| --- | --- |
| 1–2 | 라이브러리 준비, COM 포트 찾기 |
| 3–4 | 설정, 보드 사양 확인 |
| 5–6 | 연결, 신호 수집 |
| 7–8 | 표로 정리, 원본 신호 확인 |
| 9–10 | 필터링, 전후 비교 |
| 11 | RMS — 신호 세기 |
| 12 | 주파수 분석 — Alpha/Beta 등 |
| 13–14 | CSV 저장, 연결 해제 |

## 여러 보드를 동시에 쓸 때

강의실처럼 Ganglion이 여러 대 켜져 있으면, `BOARD_MAC`을 비워 두면
**옆 사람 보드에 연결될 수 있습니다.** 반드시 내 보드의 MAC 주소를 지정하세요.

> OpenBCI GUI에 보이는 `Ganglion-3587`은 블루투스 **이름**이고,
> `BOARD_MAC`이 요구하는 것은 **MAC 주소**입니다. 서로 다릅니다.

**MAC 주소 찾는 법 — 세 가지**

| 방법 | 준비물 | 비고 |
| --- | --- | --- |
| **노트북 5-A 진단 셀** | 없음 | ⭐ 가장 간단. 동글로 스캔해 MAC을 뽑아 줍니다 |
| Bluetooth LE Explorer | Windows | Microsoft Store에서 설치 후 스캔 |
| nRF Connect for Mobile | **안드로이드 폰** | 앱스토어에서 설치 후 스캔 |

> ⚠️ **iPhone으로는 안 됩니다.** iOS는 개인정보 보호 정책 때문에
> 실제 MAC 대신 무작위 UUID를 보여줍니다. 안드로이드를 쓰세요.

찾은 MAC(`d2:b4:11:81:48:ad` 형태)을 `BOARD_MAC`에 입력하면 됩니다.
**보드별로 한 번 정리해 두면** 이후 수업에서 계속 재사용할 수 있습니다.

## ⚠️ brainflow 버전 주의

**`brainflow` 를 최신 버전으로 올리지 마세요.** 연결이 안 됩니다.

| 버전 | 결과 |
| --- | --- |
| **5.20.0** | ✅ 정상 연결 |
| 5.21 이상 | ❌ BLED112 지원이 죽어 있어 실패 |

`requirements.txt` 에 `brainflow==5.20.0` 으로 고정되어 있고,
노트북 1단계 셀이 버전을 확인해 자동으로 맞춰 줍니다.

### 버전을 바꾼 뒤에는 반드시 커널 재시작

`brainflow` 를 새로 설치하거나 버전을 바꿨다면 **`Kernel → Restart Kernel`** 을 해야 합니다.

DLL은 한 번 메모리에 올라가면 **파일을 교체해도 실행 중인 커널 안에서는 바뀌지 않습니다.**
재시작하지 않으면 디스크는 5.20.0인데 커널은 옛 버전을 계속 쓰면서
**0초 만에 연결 실패**합니다.

노트북 1단계 셀이 이 상황을 감지해 알려주고, 정상일 때는 이렇게 표시됩니다.

```
준비 완료
  BrainFlow : 5.20.0   (실제 로드된 버전)
```

## 기술적 배경

내부적으로 [BrainFlow](https://brainflow.readthedocs.io/)를 사용합니다.
OpenBCI GUI v5도 같은 라이브러리를 쓰기 때문에 동작이 동일합니다.

```python
params = BrainFlowInputParams()
params.serial_port = 'COM3'    # 필수 — BLED112 동글 포트
params.mac_address = ''        # 선택 — 특정 보드 지정
board = BoardShim(BoardIds.GANGLION_BOARD, params)
```

| 파라미터 | 설명 |
| --- | --- |
| `serial_port` | **필수.** 동글이 꽂힌 COM 포트 |
| `mac_address` | 선택. 비우면 자동 탐색 |
| `timeout` | 선택. 기본 15초 |

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| **0초 만에** 연결 실패 | ① brainflow 5.20.0 인지 ② **커널 재시작했는지** |
| 오래 기다리다 실패 | 보드 전원, 배터리. 5단계가 3번 자동 재시도합니다 |
| 연결 실패 | **OpenBCI GUI 종료** (창만 닫지 말고 `javaw` 프로세스까지) |
| 포트를 못 찾음 | 동글 다시 꽂고 2단계 재실행 |
| 샘플 0개 | 보드 전원, 배터리, 전극 연결 |
| 엉뚱한 보드 연결 | `BOARD_MAC` 지정 |
| 다음 실행이 안 됨 | 14단계를 실행했는지 확인 → 커널 재시작 |
| 신호가 온통 잡음 | 전극 접촉, 레퍼런스 전극 위치 |
| 노트북 수정이 반영 안 됨 | 브라우저에서 노트북을 닫았다 다시 열기 |

> 💡 **실패까지 걸린 시간이 가장 중요한 단서입니다.**
> 0초면 라이브러리·포트 문제, 오래 걸리면 보드를 못 찾은 것입니다.
> 원인이 불분명하면 노트북의 **5-A 진단 셀**을 실행하세요.
