# OpenBCI Ganglion 신경신호 실습

UNIST **재활재생개론** 수업용 실습 코드.
BLED112 동글로 OpenBCI Ganglion 보드에 연결해 신경신호(EEG/EMG)를 수집하고 처리합니다.

MATLAB Live Script 실습을 **Jupyter Notebook**으로 옮긴 것으로,
설명과 코드가 한 화면에 함께 있어 단계별로 따라가며 학습할 수 있습니다.

---

## 준비물

- **OpenBCI Ganglion 보드** — 4채널 · 200 Hz
- **BLED112 USB 동글**
- Python 3.9 이상

---

## 시작하기

### 1. 설치

```powershell
pip install -r requirements.txt
```

### 2. 노트북 실행

```powershell
jupyter notebook src/Ganglion_Tutorial.ipynb
```

브라우저가 열리면 **셀을 위에서 아래로** 하나씩 실행합니다 (`Shift + Enter`).

### 3. 설정

노트북 **3단계 셀**에서 세 가지만 고치면 됩니다.

```python
COM_PORT     = 'COM3'      # 동글 포트 (2단계에서 확인)

```

> ⚠️ **OpenBCI GUI는 반드시 종료하세요.** 동글은 한 번에 한 프로그램만 쓸 수 있습니다.

## ⚠️ 여러 보드를 동시에 쓸 때 (강의실)

### MAC 지정은 통하지 않습니다

`BOARD_MAC` 을 넣어도 **보드가 선택되지 않습니다.** BrainFlow 가 값을 받아
로그에 찍기는 하지만 실제 필터링에는 쓰지 않아, **먼저 응답한 보드에 연결**됩니다.

실측 근거 (2026-07-24, 보드 2대):

| 지정한 MAC | 결과 |
| --- | --- |
| `f6:83:23:ca:c1:29` (실제 보드 A) | 연결됨 |
| `c5:cf:b4:83:e8:c6` (실제 보드 B) | 연결됨 |
| `11:22:33:44:55:66` (**존재하지 않는 가짜**) | **연결됨** ← MAC 이 무시된다는 증거 |

BrainFlow 로그도 `search for 11:22:33:44:55:66` 를 찍은 뒤 그냥 연결합니다.

### ✅ 실제로 통하는 방법

**1) 내 보드만 켠다 — 가장 확실**

주변에 다른 Ganglion 이 없으면 자동 탐색이 정확합니다.

**2) 한 대씩 순서대로 연결한다**

BLE 보드는 연결되고 나면 광고를 멈추므로, 이미 연결된 보드는 다음 사람에게 잡히지 않습니다.

```
모든 보드 OFF
  → 1번 학생: 보드 ON → 연결 → 유지
  → 2번 학생: 보드 ON → 연결 → 유지
  → ...
```

**3) 연결 후 반드시 확인한다**

연결한 뒤 **팔에 힘을 줘 보세요.** 신호가 반응하면 내 보드입니다.
반응이 없으면 남의 보드일 수 있으니 연결을 해제하고 다시 시도하세요.
(2차시 노트북의 5단계가 이 확인을 겸합니다.)

### 주변 상황 확인용 스캔 셀

노트북의 **「주변 Ganglion 확인」 셀**은 지금 몇 대가 켜져 있는지 보여줍니다.
1대뿐이면 안심하고 연결하면 되고, 여러 대면 위 절차를 따르면 됩니다.

```
================================================================
주변 Ganglion 2대 감지
================================================================
  Ganglion-3587        f6:83:23:ca:c1:29   신호  -58 dBm  <- 가장 가까움
  Ganglion-c57c        c5:cf:b4:83:e8:c6   신호  -69 dBm

2대가 켜져 있습니다. 주의가 필요합니다.
```

> 이름(`Ganglion-3587`)은 OpenBCI GUI 에 보이는 것과 같으므로, 내 보드가
> 켜져 있는지 확인하는 용도로 유용합니다. 다만 **연결 대상을 고르는 데는 쓸 수 없습니다.**

## ⚠️ brainflow 버전 주의

**`brainflow` 를 최신 버전으로 올리지 마세요.** 연결이 안 됩니다.

| 버전 | 결과 |
| --- | --- |
| **5.20.0** | ✅ 정상 연결 |
| 5.21 이상 | ❌ BLED112 지원이 죽어 있어 실패 |

`requirements.txt` 에 `brainflow==5.20.0` 으로 고정되어 있고,
노트북 1단계 셀이 버전을 확인해 자동으로 맞춰 줍니다.

### 버전을 바꾼 뒤에는 반드시 커널 재시작

`brainflow` 를 새로 설치하거나 버전을 바꿨다면 **`Kernel → Restart Kernel`** 을 해야 합니다.

DLL은 한 번 메모리에 올라가면 **파일을 교체해도 실행 중인 커널 안에서는 바뀌지 않습니다.**
재시작하지 않으면 디스크는 5.20.0인데 커널은 옛 버전을 계속 쓰면서
**0초 만에 연결 실패**합니다.

노트북 1단계 셀이 이 상황을 감지해 알려주고, 정상일 때는 이렇게 표시됩니다.

```
준비 완료
  BrainFlow : 5.20.0   (실제 로드된 버전)
```

## 기술적 배경

내부적으로 [BrainFlow](https://brainflow.readthedocs.io/)를 사용합니다.
OpenBCI GUI v5도 같은 라이브러리를 쓰기 때문에 동작이 동일합니다.

```python
params = BrainFlowInputParams()
params.serial_port = 'COM3'    # 필수 — BLED112 동글 포트
params.mac_address = ''        # 선택 — 특정 보드 지정
board = BoardShim(BoardIds.GANGLION_BOARD, params)
```

| 파라미터 | 설명 |
| --- | --- |
| `serial_port` | **필수.** 동글이 꽂힌 COM 포트 |
| `mac_address` | 선택. 비우면 자동 탐색 |
| `timeout` | 선택. 기본 15초 |

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| **0초 만에** 연결 실패 | ① brainflow 5.20.0 인지 ② **커널 재시작했는지** |
| 오래 기다리다 실패 | 보드 전원, 배터리. 5단계가 3번 자동 재시도합니다 |
| 연결 실패 | **OpenBCI GUI 종료** (창만 닫지 말고 `javaw` 프로세스까지) |
| 포트를 못 찾음 | 동글 다시 꽂고 2단계 재실행 |
| 샘플 0개 | 보드 전원, 배터리, 전극 연결 |
| 엉뚱한 보드 연결 | `BOARD_MAC` 지정 |
| 다음 실행이 안 됨 | 14단계를 실행했는지 확인 → 커널 재시작 |
| 신호가 온통 잡음 | 전극 접촉, 레퍼런스 전극 위치 |
| 노트북 수정이 반영 안 됨 | 브라우저에서 노트북을 닫았다 다시 열기 |

> 💡 **실패까지 걸린 시간이 가장 중요한 단서입니다.**
> 0초면 라이브러리·포트 문제, 오래 걸리면 보드를 못 찾은 것입니다.
> 원인이 불분명하면 노트북의 **5-A 진단 셀**을 실행하세요.

## 2차시 · 실시간 손동작 분류

`Ganglion_Tutorial_2_Classification.ipynb` — 팔뚝 EMG로 **가위·바위·보를 실시간 판별**합니다.

```
팔 근육 EMG → 필터(30-95Hz) → 특징 추출(포락선 평균)
   → 캘리브레이션(동작×40회) → Random Forest → 모델 저장 → 실시간 판정
```

1차시(EEG, 신호를 **본다**)와 달리 2차시는 EMG로 신호를 **판단**합니다.
`scikit-learn` 이 추가로 필요하며 `requirements.txt` 에 포함되어 있습니다.

**핵심 설계**
- 학습한 모델을 `joblib` 로 저장 → 다음 주에 불러와 비교 (전극 위치·개인차 실험)
- 시간순 분할로 정직하게 평가 (무작위 분할은 이웃 샘플 누수로 과대평가)
- 최근 5회 예측 다수결로 실시간 판정 안정화
- **관문 2곳**: 실시간 신호 확인(5단계), 활성 지문 확인(8단계) — 여기서 전극 문제를 미리 걸러냄
